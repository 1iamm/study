# 吉他第 1 课｜课后作业

## 作业一：六个把位音阶

- 背下六个把位的音阶。
- 当前先记指型和指法顺序，暂不要求记每个音名。
- 能按指型演奏。

速度/BPM、次数、每日时长、录音/视频要求、截止时间：**未明确布置**。

## 作业二：四音一组音阶模进

- 背下课堂所教的四音一组模进。
- 从 Mi 开始，连续弹到后面的音组。
- 一组接一组连起来，不看谱完成。
- 当前练第一把位；其他把位之后再讲。
- 暂时不追求速度。

次数、每日时长、录音/视频要求、截止时间：**未明确布置**。

## 作业三：带伴奏的小练习曲

- 跟着课堂展示或发送的伴奏练习曲弹出来。
- 用脚打拍，控制每个音的时值。
- 完整演奏，达到接近老师示范视频的完成度。

曲名、具体小节、完整和弦顺序、BPM、次数、每日时长、录音/视频提交要求、截止时间：**未明确布置**。

## 学习方向：Logic / MIDI

老师建议在 B 站学习 Logic 编曲或 Logic 录音的基本操作，了解键盘、鼓、其他声部和吉他实录如何进入电脑编曲流程。

这项没有具体教程、学习时长、成果要求或截止时间，因此记录为**学习方向**，不作为量化作业。

## 器材准备

- 向同学借一把电吉他。
- 后续将进入电吉他内容；最开始可以暂时不用音箱，后续需要。
