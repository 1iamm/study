# 吉他第 1 课｜课中问题

## 课程主题与进度

**主题：** 吉他基础技术、把位音阶与节奏训练。

**本节目标：**

1. 梳理从当前基础到编曲、即兴与 Solo 的学习顺序。
2. 练习拨片、右手交替拨弦、把位音阶和音阶模进。
3. 用脚打拍，识读音符时值，并跟伴奏完成小练习曲。
4. 初步了解编曲中的音区分配、MIDI 与 Logic。

## 1. 学习顺序

老师认为目前需要先补足演奏技术与基础，顺序包括：

1. 音阶；
2. 调与不同调中的演奏；
3. 和弦及和弦进行；
4. 演奏技术；
5. MIDI、录音和电脑编曲操作。

乐理有助于理解音程、和弦构成和可用音；创作也需要先获得好听的旋律，再分析和整理。

## 2. 拨片与右手

- 拨片要采用**下、上交替拨弦**，不要连续只向同一方向拨。
- 建立交替拨弦习惯有助于之后提高速度。
- 老师对当前整体手部情况评价“大概还行”，但交替拨弦需要继续建立。
- 本节没有明确系统讲解右手手腕角度、拨片露出长度、拨弦深度、扫弦或杂音处理，因此不在本笔记中补充。

## 3. 把位音阶与指法

### 第一、第二把位

- 第一把位是以前练过的内容，本节能够演奏。
- 开始学习第二把位；老师要求上行与下行使用对应、对称的指法：怎么弹上去，就怎么弹回来。
- 练习中包含跨弦/换指；不能始终用同一种方式“串过去”。
- 某些位置需要提前收回或抬起手指；具体手指和位置因转写不可靠，不写入结论。

### 多个把位音阶

- 老师介绍了六个把位音阶。
- 当前重点：先记住**指型和指法顺序**，暂不要求立刻记住每一个音名。
- 后续会学习如何将音阶应用于编曲和 Solo。
- 旅行木吉他的品位/琴颈范围可能限制后面部分音的完整演奏。

### 均匀性与节拍器

- 老师指出音阶弹奏不够均匀。
- 当前先听清自己是否弹得均匀，再把节拍器与整体演奏结合；不要只逐音机械跟节拍器。
- 本节没有给出把位音阶的 BPM、次数或每日时长。

## 4. 四音一组音阶模进

练习逻辑：从任一音开始，向后连续取四个音；下一组从后一个音开始，连续连接。

课堂上行示例：

```text
Mi–Fa–Sol–La
Fa–Sol–La–Si
Sol–La–Si–Do
La–Si–Do–Re
```

要求：

- 从六弦空弦开始；
- 使用上下交替拨弦；
- 四个音一组，一组接一组，不把每个音割裂；
- 可唱出唱名，以训练唱音与听觉；
- 暂时不追求速度，先做到不看谱、连续弹奏。

## 5. 节奏与脚打拍

- 脚**落地瞬间**算拍点；抬脚是为下一次落拍做准备。
- 抬脚过程可以理解为后半拍，但不能把一次落脚和一次抬脚当成两个完整拍来数。
- 演奏时要同时听自己的声音、脚下拍点和伴奏，不能只靠感觉进入。
- 本节涉及四分、八分、十六分音符，以及全音符四拍、附点二分音符三拍。
- 课堂没有明确给出 BPM、拍号或完整数拍口令，因此不自行补充。

## 6. 小练习曲与伴奏

- 练习曲要求跟伴奏演奏，并用脚打拍、控制每个音的时值。
- 有两根弦同时演奏的音型，老师要求用拨片同时拨两根弦，而非手指分别拨。
- 谱中讲到 C、A、E 等和弦和不同音符时值，但完整顺序和具体小节未可靠保留。
- 老师要求知道自己已打几拍、弹到哪个位置，速度不能忽快忽慢。

## 7. 编曲、MIDI 与 Logic

- 完整编曲可包括 Solo/主旋律、伴奏、鼓、键盘与其他声部。
- 编曲流程包括：MIDI、电脑录音、写键盘与鼓、录制吉他、合成小样、反复试听修改。
- 吉他、贝斯、键盘可分配不同音区：贝斯承担低频，吉他可弹中间音区，键盘可在更高音区；不必每次都把和弦所有音都弹全。
- 老师建议后续学习 Logic 编曲或录音的基本操作。

## 8. 本节个人卡点

1. 第二把位与跨弦/换指不熟。
2. 上行、下行的对应指法不清楚。
3. 音阶唱名顺序容易混乱。
4. 右手尚未稳定使用上下交替拨弦。
5. 音与音之间不够均匀。
6. 脚落地、抬脚与半拍之间的关系尚在建立。
7. 带伴奏时进入位置和音符时值不稳定。

## 9. 本节肯定

- 第一把位已经会弹。
- 部分指法调整后，老师多次确认“对 / 对了”。
- 理解“抬脚过程属于后半拍”后，老师确认理解正确。
- 理解电脑小样、试听和修改的编曲流程后，老师予以确认。
