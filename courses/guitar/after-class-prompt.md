# 吉他课后提示词

```text
请处理刚才的吉他课程 Record。找出所有以“标记：”和“阶段：”开头的内容，并结合我上传的谱例、截图和老师反馈整理。

要求：
1. 按课程顺序建立“阶段—书签—老师指令”结构；没有可靠时间码时不要编写精确时间。
2. 每个书签只输出：问题/目标、老师要求、老师明确给出的动作或节奏、老师明确给出的检查方法。
3. 只记录老师明确说过的 BPM、时长、次数、速度规则和完成标准；不要生成练习计划或自行补充。
4. 对无法从转写确认的手型、音色或节奏，标“待补充”；若它影响整理或作业执行，直接向我提问，不要猜。
5. 最后列出作业原文及老师明确给出的完成要求；不要列“要问老师的问题”。
```
