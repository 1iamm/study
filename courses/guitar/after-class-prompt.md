# 吉他课后提示词

```text
请处理刚才的吉他课程 Record。找出所有以“标记：”和“阶段：”开头的内容，并结合我上传的谱例、截图和老师反馈整理。

要求：
1. 按课程顺序建立“阶段—书签—老师指令”结构；没有可靠时间码时不要编写精确时间。
2. 每个书签输出：问题/目标、老师要求、正确动作或节奏、检查方法、当天最小练习。
3. 输出本周最多 3 项优先改进项，以及 15/30/45 分钟练习计划；节奏练习必须写 BPM 和提速规则。
4. 对无法从转写确认的手型、音色或节奏，明确标“需要截图、练习录音或老师确认”，不要猜。
5. 最后列出作业原文、下次课前完成标准和要问老师的问题。
```
