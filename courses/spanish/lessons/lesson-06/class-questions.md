## 课中重点与个人卡点

### 发音与重音

- `él / el` 的起始元音反复受英语字母名影响；要按西语的 `e` 音读，不读成英语字母 L。
- `usted` 为两个音节，老师明确重音在最后一个音节。
- `hablamos` 的重音曾被老师提醒；本次转写未可靠保留具体口型说明。
- `hospital`、`colegio` 也受英语发音影响：前者不要照英语 `hospital` 读，后者不要照英语 `college` 读。
- `internet` 要跟随老师示范；本次转写不能可靠还原其具体音值。

### 动词变位：把 `hablar` 的规则迁移到 `trabajar`

| 原形 | 变位 | 含义 |
| --- | --- | --- |
| `trabajar` | `trabajo` | 我工作 |
| `trabajar` | `trabaja` | 他／她／您／单数名词主语工作 |

- 在句中担任谓语的动词必须变位，不能直接使用原形。
- 读句子时先找变位动词，再找主语，再判断人称。
- 卡点：看到 `trabaja` 时，曾因少了原形结尾 `-r` 而没有立刻认出它是第三人称单数变位。

### 问工作地点

| 句子 | 说明 |
| --- | --- |
| `¿Dónde trabaja un mecánico?` | 一个机械师在哪里工作？主语是句末的 `un mecánico`，不是被省略的“你”。 |
| `Un mecánico trabaja en un taller.` | 一个机械师在修理厂工作；教材的冠词形式未可靠保留，现阶段以句型理解为主。 |
| `Yo trabajo en una empresa de internet.` | 我在一家互联网公司工作。 |
| `Yo trabajo en Meituan.` | 我在美团工作。 |

- `en` 表示地点；不能机械地只等同英语 `in`，可先理解为“在……”。
- `de` 在 `empresa de internet` 中连接类别／所属关系；不要和表示地点的 `en` 混淆。

### 职业介绍与阴阳性

- 直接介绍职业时，通常不在职业前加 `el / la`：`Soy programador.`、`Soy profesora.`
- 职业名词常以 `-o / -a` 区分男性与女性：`el médico / la médica`、`el camarero / la camarera`、`el secretario / la secretaria`、`profesor / profesora`。
- `periodista` 的词形不随性别变化，通过冠词区分：`el periodista / la periodista`。
- `un / una` 随名词阴阳性变化：`un curso`、`un mecánico`、`una empresa`。
- 个人卡点：不能将 `periodista` 强行按 `-o / -a` 改写，也不要把职业名词阴阳性和动词变位混在一起。

### 形容词与词性

- `bueno / buena` 是形容词；`buenos días` 因 `día` 为阳性而用 `buenos`，`buenas noches` 因 `noche` 为阴性而用 `buenas`。
- 卡点：曾说成 `Buenos noches.`。
- `grande` 表示“大”；本课按词尾 `-e`、词形不随阴阳性变化理解，例如 `grande empresa`。

### 告别表达

| 表达 | 本课含义与使用场景 |
| --- | --- |
| `hasta luego` | 最通用的“再见”；无需明确下次何时见。 |
| `adiós` | 普通“再见”，可用于口语和书面语。 |
| `hasta mañana` | 明天见；明确知道明天会见时使用。 |
| `hasta esta noche` | 今晚见；明确当晚会再见时使用。 |
| `hasta pronto` | 很快再见、近期再见；有期待不久再见的意味。 |
| `hasta ahora` | 极短时间内再见，例如一小时内。 |
| `hasta la vista` | 后会有期；更常见于文学或影视，不是日常首选。 |

### 新职业与地点词汇

- 工作地点：`bar`（酒吧）、`hospital`（医院）、`taller`（修理厂）、`colegio`（学校，主要指中小学）、`universidad`（大学）、`oficina`（办公室）、`en casa`（在家）。
- 职业：`médico / médica`、`camarero / camarera`、`secretario / secretaria`、`profesor / profesora`、`mecánico`、`periodista`、`ama de casa`、`programador`。
- `periódico` 在本课的具体词义（报纸、报社或其他）转写不可靠，不纳入固定记忆。

## 本节反馈与复习优先级

1. 先熟练说出职业与工作地点：`¿Dónde trabaja un mecánico?` → `... trabaja en un taller.`
2. 重点纠正 `él / el`、`usted` 和 `hablamos` 的英语化发音。
3. 将上节课的动词规则迁移到新动词：`trabajar → trabajo / trabaja`。
4. 不只背单词，要能连续完成“来自哪里—会说什么语言—职业—工作地点”的问答。
