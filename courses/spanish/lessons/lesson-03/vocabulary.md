# 西班牙语第 3 课｜单词与短句

| 单词 / 短句 | 语义与用法 | 学习课次 |
| --- | --- | --- |
| `Buenas tardes.` | 下午好 / 晚上好。具体使用时间边界按老师下次确认的版本记忆。 | 第 3 课 |
| `Buenos días.` | 早上好 / 上午好。 | 第 3 课 |
| `Buenas noches.` | 晚安；本节先记作离别、结束聊天或准备休息时使用。 | 第 3 课 |
| `Hola.` | 你好。 | 第 3 课 |
| `¿Qué tal?` | 最近怎么样 / 怎么样。作为问句要有疑问语调。 | 第 3 课 |
| `Adiós.` | 再见 / 拜拜。 | 第 3 课 |
| `amigo` | 朋友。 | 第 3 课 |
| `qué` | “什么”；本节作为带重音符号的疑问词学习。 | 第 3 课 |
| `tarde` | 下午 / 傍晚；本节作为阴性名词学习。 | 第 3 课 |
| `día` | 天 / 白天；本节作为阳性名词学习。 | 第 3 课 |
| `buenas` | “好的”的阴性复数形式；如 `buenas tardes`。 | 第 3 课 |
| `buenos` | “好的”的阳性复数形式；如 `buenos días`。 | 第 3 课 |
