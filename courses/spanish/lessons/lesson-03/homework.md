# 西班牙语第 3 课｜课后作业

## 老师明确布置的作业

1. **继续练习本节复查的拼读与发音。**
   - 优先练习本节反复读错的辅音和音节组合。
   - 在熟练拼读前，下节课不会继续进入音节划分。
2. **把本次使用的课件 / 相关语音练习发给老师。**
   - 老师收到后会继续帮助纠错，因为自己回听录音时可能不易听出差别。
3. **发送时间：** 明天或后天，最迟在周一上课前。

> 本次录音中没有听到其他明确的书面作业、页码作业或背诵数量要求。

## 建议执行清单

- [ ] 从课件中找出老师反复纠正的 `ga/go/gu` 与“咔 / 克拉”相关组合，逐组慢读。
- [ ] 分别练 `ra, re, ri, ro, ru`；练习时避免把明显的 d / t 加在前面。
- [ ] 单独练词尾 r 的“轻颤后收住”；不确定例词时不自行猜测。
- [ ] 复习 B / V、Y / LL、Ñ / N、J / G、QUE / QUI。
- [ ] 跟读：`Buenas tardes`、`Buenos días`、`Buenas noches`、`Hola`、`¿Qué tal?`、`Adiós`。
- [ ] 朗读 `¿Qué tal?` 时加入明确的疑问语调。
- [ ] 将课件或练习录音发送给老师，并附上本课“待确认问题”。
