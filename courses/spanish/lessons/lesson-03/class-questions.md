## 1. 本节发音重点与个人卡点

### 1.1 不要把目标音读成“咔 / 克 / 克拉”

- 老师反复纠正：“不是咖，是嘎”“没有‘科’的音”“不能‘克拉’”。
- 练习方向：与 `ga / go / gu` 的感觉靠近，不要回到中文或英语式 `ka / ko / ku`。
- **个人卡点：** 第一次能读对，重复时容易又读成“咔、克拉”；自己回听录音也不易分辨。
- **待核对：** 转写没有保留具体课件组合和例词；下次请老师确认对应的是 `C/G` 的哪一组拼读。

### 1.2 辅音加 r：不要读成英语式 TR / DR

- 练习阶段可以暂时用“得拉、卓”等辅助感觉，但正常说话时不能把明显的 `d` 或 `t` 加在前面。
- 老师的目标方向是 `ra, re, ri, ro, ru`；具体示范在转写中失真。
- **个人卡点：** 不加“得”很难直接发出；需要慢练，不要求立刻完全做到。

### 1.3 词尾 r：收住并尽量单颤

- 老师要求词尾读完有“收住”的感觉；能做到时，颤一下后自然收住。
- **个人卡点：** 单颤 r 不稳定，容易额外加辅音。
- **待核对：** 转写中的词尾 r 例词不可靠，不能据此确定具体单词。

## 3. 阴阳性与单复数配合

1. 名词和形容词要区分阴阳性；形容词应与其修饰的名词一致。
2. `tarde` 是阴性名词，因此使用阴性形容词：`buenas tardes`。
3. `día` 是阳性名词，因此使用阳性形容词：`buenos días`。
4. 两边的 `s` 体现复数配合：`buenas tardes` 是阴性复数形容词 + 阴性复数名词。
5. 初步记忆：以 `a` 结尾的形容词通常用阴性形式，以 `o` 结尾通常用阳性形式；老师已提醒后面会有例外，需要单独记。

## 4. 重音符号与疑问语调

- `¿Qué tal?` 中的 `qué` 带重音符号，是疑问词。
- 按老师本节课的学习方式，先把“带重音符号”和“不带重音符号”视作意思不同的两个词处理，不要只理解为同一词随意带或不带重音。
- 疑问句有时与陈述句语序相同，因此需要通过语调明确表示提问。
