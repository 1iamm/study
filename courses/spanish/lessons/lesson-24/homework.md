### 千、几十万、百万

下表是依据本节已确认数量整理的标准复习形式，不声称每一项都是你课堂说出的逐字答案。

| 数量 | 西语 |
| --- | --- |
| 一千 | mil |
| 两千 | dos mil |
| 一万 | diez mil |
| 七十万 | setecientos mil |
| 八十万 | ochocientos mil |
| 九十万 | novecientos mil |
| 一百万 | un millón |
| 两百万 | dos millones |
| 八百万 | ocho millones |

记忆要点：

- 基数结构“数词 + mil”中 mil 不加 s。
- 70 万是 700 个千，不是 70 个千。
- millón／millones 有单复数变化；八百万 ocho millones 本课当堂答对。
- millones 直接连接所数名词时用 de，例如 millones de personas。不自行补教材未确认的人口数字。
