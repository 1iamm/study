## 课中重点与个人卡点

### 1. 词汇复习与口语表达

- 上节课复习中可可靠确认：`gato`（猫）、`colegio`（学校）、`ropa`（衣服）、`parque`（公园）。
- `ropa` 在这里是集合名词；课堂确认其不按普通可数名词理解。
- `No pasa nada.`：没关系、没事；当前口语情境中，单说 `Nada.` 也可以。
- 卡点：`ropa` 一度想不起来；部分旧词能认出，但口头反应较慢。

### 2. 联系、预约与邮件

- `contacto con ...`：与……有联系／往来。
- `reserva` 是阴性名词，表示预约、预订；`hacer una reserva`：进行预约／预订。
- `correo`：邮件、邮箱；`correo electrónico`：电子邮件。
- `o`：或者；`Eso es.`：对，就是这样／没错。
- 与顾客、预约和邮件有关的课文完整句：待补充。

### 3. 形容词变副词：`-mente`

- 以 `-mente` 结尾的词是副词；但不能反推“所有副词都以 `-mente` 结尾”。
- 老师给出的构词步骤：可分阴阳性的形容词，先变为阴性，再加 `-mente`；如以 `bonito → bonita` 为例。
- 本身不发生阴阳性变化的形容词，直接加 `-mente`。
- 语法上可以构成，不等于实际表达中一定常用。
- `bonita + mente` 的完整示例、课堂另一个不变形形容词：待补充。

### 4. `recibir`、`tener` 与 `hacer`

- `recibir`：接收、接受；与之前的 `Lo he recibido.` 有关联，但本节重点回到一般现在时。
- `-ir` 动词：第一人称单数词尾是 `-o`；第一人称复数词尾是 `-imos`。`recibir` 的其他完整变位不根据转写猜写。
- `tener`：有、拥有。本节能够回忆 `tengo`，老师肯定整体回忆不错。
- `hacer`：做；课堂明确出现 `hacemos`。第一人称单数是特殊形式，但具体形式在本次转写中保留为待补充。
- 卡点：对 `-ir` 动词变位印象弱，规则 `-ar` 动词较熟但 `-er / -ir` 尚未形成稳定记忆。

### 5. 语序与长句分析

- `¿Qué hacen los clientes?`：这些顾客做什么？特殊疑问词 `qué` 必须在前；西语主语可以放在动词后。
- 不能用英语固定 SVO 语序机械解析西语；前置成分往往是信息重点。
- 长句分析步骤：
  1. 先找发生人称变位的动词，即谓语；
  2. 确认谓语含义；
  3. 问“谁／什么做了什么、有什么”，再找宾语和其他成分；
  4. 若主语省略，依据动词人称、前文名词和句义共同判断。
- 例：`tenemos` 是“我们有”，可作为长句分析的起点。
- `para` 不必机械译作“为了”；在 `para problemas y preguntas` 一类语境中可随整体理解为“对于……”。
- 卡点：看到“动词 + 主语”时仍会受英语语序影响。

### 6. 数字与 `ser`

- `treinta y cuatro`：34；本节能从听到的西语数字迅速反应出数字，老师明确肯定听力反应很好。
- `ser` 的本节可靠复习形式：`soy`、`es`、`somos`、`son`；老师评价“背得很不错”。
- `Es muy mayor.`：他／她年纪很大；此处 `mayor` 是年长的、年老的，不是“好”。
- `muy` 和 `bien` 本课均按副词理解；`Muy bien.` 适合评价动作或表现，不能机械用来描述一个人的性质。

### 7. 颜色与形容词性别

| 词汇 | 含义与重点 |
| --- | --- |
| `negro` | 黑色的；本节重点纠正实际单词发音与字母名称的混淆。 |
| `blanco / blanca` | 白色的／白色的（阴性）；`Blanca` 也常是女性名字。 |
| `rojo` | 红色的。 |
| `amarillo` | 黄色的；本节有发音纠正。 |
| `verde` | 绿色的；不属于典型 `-o → -a` 变化形式。 |
| `azul` | 蓝色的；具体发音规则待补充。 |

- 颜色在本页按形容词学习，很多需要与被描述名词的性别配合。
- 卡点：对单独字母名称和单词中的实际发音反复混淆；`amarillo`、`azul` 有读音问题。

### 8. 人物外貌与性格

- `hermano / hermana`：兄弟／姐妹；熟人间 `hermano` 有时带“哥们”感，女性正常用 `hermana`。
- `amigo / amiga`：男性朋友／女性朋友；`una amiga` 不等于女朋友，`novia` 才是女朋友。
- `porque`：因为；`¿Por qué?`：为什么。完整的拼写／重音说明待补充。
- `recibo`：我接收／我接待；`pelo`：头发；`ojos`：眼睛，描述人的眼睛时通常用复数。
- `bastante`：相当、挺；程度弱于 `muy`。`bastante guapo`：挺帅／很帅。
- `corto / largo`：短的／长的，可描述头发；`bajo / baja`：矮的、低的，词尾帮助判断所描述对象性别。
- `simpático / simpática`：亲切的、好相处的；`antipático`：不太讨人喜欢；`un poco`：有一点。
- `guapo / guapa`：帅的／漂亮的；`serio`：严肃的；`moreno`：小麦色、棕色，当前具体修饰对象待补充。
- `a veces`：有时候；`demasiado`：太、过于；`llevar` 在本课人物描述中近似“有／带着”，其他含义下节课再讲。
