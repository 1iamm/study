## 课中重点与个人卡点

### 1. 天气、颜色与人物色彩特征

- `el tifón`：台风，阳性名词；由学习者课堂手记确认。
- 本节新增 `morado / morada`（紫色的，阳／阴）；复习 `rojo`、`negro`、`amarillo`、`verde`、`azul`、`marrón`。
- 粉色词的准确拼写：待补充；课堂仅确认它不随阴阳性变化。
- `rubio`：金黄色、金发的；不要与普通黄色 `amarillo` 混淆。
- `moreno / morena`：深色、棕黑褐色或小麦色的人物特征；具体指肤色还是头发需看语境。
- 卡点：曾把 `azul` 当紫色，把 `morena` 当“漂亮”，后文再次混淆 `moreno`、`rubio` 和普通黄色。

### 2. 年龄与自我介绍

课堂确认的自我介绍：

- `Tengo veintisiete años.`：我 27 岁。
- `Tengo el pelo corto.`：我留短发／我的头发是短的。
- `Soy muy simpático y sociable.`：我很友善，也很合群。
- `Tengo los ojos marrones.`：我的眼睛是棕色的；`ojos` 与 `marrones` 都用复数。

第二次完整介绍得到老师连续肯定。主要卡点：`años` 发音、忘记 `soy`、`llevar` 人称混用、误用 `pero`、`marrones` 发音和复数配合。

### 3. 人物外貌与穿戴

| 词汇 | 含义与用法 |
| --- | --- |
| `pelo / pero` | 头发／但是；近音易混，`pero` 只用于真正的转折。 |
| `corto / largo` | 短的／长的；`largo` 也可表示时间漫长。 |
| `delgado` | 瘦的。 |
| `llevar / llevo` | 携带、穿、戴／我携带、穿、戴。 |
| `gafas` | 眼镜；通常使用复数。 |
| `sombrero` | 帽子；课堂偏向有较大帽檐的帽子。 |
| `barba / bigote` | 胡子／上唇胡须、八字胡。 |
| `chico / chica` | 小伙子、男孩／小姑娘、女孩。 |
| `hombre / mujer` | 男人、丈夫／女人、妻子；具体含义依语境。 |

- “卷曲的”、大的、小的、日常鸭舌帽以及高级胡须词的准确拼写：待补充。
- `pelo` 与 `pero` 必须对照记；不能把 `pero` 当“然后”随意连接两个并列优点。

### 4. 性格与程度副词

- `alegre`（快乐、高兴）和 `sociable`（合群、善于社交）不按 `-o / -a` 改变性别。
- `simpático / simpática`：友善、讨人喜欢；描述女性时使用阴性形式，课堂运用得到老师肯定。
- `generoso`：慷慨、大方；`amable`：和蔼、和蔼可亲；`tímido`：害羞、胆怯、内向。
- 程度由弱到强大致为：`un poco → bastante → muy → demasiado`。
- 课堂百分比只是帮助理解，不能当成严格语法数值；`muy` 的实际强度还受语气和语境影响。
- `bastante` 很实用，可避免初学时只会反复使用 `muy`。

### 5. 三组指示词

| 距离 | 阳性单数 | 阳性复数 | 阴性单数 | 阴性复数 |
| --- | --- | --- | --- | --- |
| 靠近说话人：这个／这些 | `este` | `estos` | `esta` | `estas` |
| 靠近听话人：那个／那些 | `ese` | `esos` | `esa` | `esas` |
| 离双方都远：那个／那些 | `aquel` | `aquellos` | `aquella` | `aquellas` |

- `esta manzana`：这个苹果；指示词放在名词前限定名词。
- 在双方都知道所指对象时，指示词也可单独使用。
- 必须同时记住距离、性别和数量；不能只机械地在单数后加 `s`。
- 注意 `esta`（这个，阴性）不带重音；不要与动词形式 `está` 混淆。

### 6. `ser` 与 `estar`

- `ser`：身份、较固定的性质和性格。例如 `Soy un chico.`、`Soy muy simpático y sociable.`。
- `estar`：状态、暂时或可能变化的情况；婚姻状态和食物当前的甜、咸等味道，本课使用 `estar`。
- 课堂手记记录的 `estar` 现在时：

| 人称 | 变位 |
| --- | --- |
| yo | `estoy` |
| tú | `estás` |
| él / ella / usted | `está` |
| nosotros / nosotras | `estamos` |
| vosotros / vosotras | `estáis` |
| ellos / ellas / ustedes | `están` |

- 除 `estoy`、`estamos` 外，其余本表形式需注意书面重音。
- `casada`：结婚的（阴性）；课堂用于婚姻状态。单身词的准确拼写仍待补充。
- `están separados`：他们处于分居状态。主语复数，所以动词和形容词都用复数；混合性别群体使用阳性复数。

### 7. 物主形容词、定冠词与人物关系

- `mi / mis`：我的；分别搭配单数／复数名词。
- `su`：他的、她的、您的、他们的等，具体拥有者依上下文判断；它不是主语代词。
- `él`：他，是主格人称代词；不要与 `su` 混为一类。
- 定冠词：

|  | 单数 | 复数 |
| --- | --- | --- |
| 阳性 | `el` | `los` |
| 阴性 | `la` | `las` |

- `mejor / mejores`：最好的（单数／复数）。
- `hijo / hija`：儿子、男孩／女儿、女孩；全女性复数用 `hijas`，只要群体中有男性就用 `hijos`。
- `profesor / profesora`：男老师／女老师；`yoga`：瑜伽；`con`：和、与。

### 8. 阅读方法与其他表达

- `Diego, el chico moreno, ...` 中 `el chico moreno` 是同位语，用来补充说明 Diego；阅读时可先跳过同位语，优先寻找谓语。
- `son`：`ser` 第三人称复数；第三人称复数动词经常以 `-n` 结尾，要建立识别敏感度。
- `solo`：单独地、独自地。
- `en el segundo piso`：在二楼；`piso` 可指楼层，也可指一套住房。
- `mujer mayor`：年长的女人；`mayor` 是年长的，不是英语中的 mayor。

## Record 误识别提醒

- `Defon／地风` 对应课堂手记确认的 `el tifón`。
- `A社／A赛／ASDOS` 是指示词部分的误识别，正确完整表以本文件课堂手记为准。
- `Aster / A-star / Hesto` 混淆了 `este / esta / estar`。
- `Professor La` 对应教师阴阳性内容；采用已学过的 `profesor / profesora`。
- `Annios`、`Madrones` 分别是 `años`、`marrones` 的误识别。
