## 核心语法：`gustar`

### 0. 老师资料中的主格、宾格与与格对照

| 人称 | 主格代词 | 直接宾语代词 | 间接宾语代词 |
| --- | --- | --- | --- |
| 第一人称单数 | `yo` | `me` | `me` |
| 第二人称单数非正式 | `tú` | `te` | `te` |
| 第二人称单数正式 | `usted` | `lo / la` | `le` |
| 第三人称单数阳性 | `él` | `lo` | `le` |
| 第三人称单数阴性 | `ella` | `la` | `le` |
| 第一人称复数 | `nosotros / nosotras` | `nos` | `nos` |
| 第二人称复数非正式（西班牙） | `vosotros / vosotras` | `os` | `os` |
| 第二人称复数正式 | `ustedes` | `los / las` | `les` |
| 第三人称复数阳性 | `ellos` | `los` | `les` |
| 第三人称复数阴性 | `ellas` | `las` | `les` |

`gustar` 结构使用右侧的间接宾语代词列，不要按直接宾语的 `lo / la / los / las` 选择。

### 1. 基本视角

老师使用“某物使某人喜欢”的直译帮助入门。自然中文仍翻译为“某人喜欢某物”。

以 `Me gusta el café.` 为例：

- `me`：感受到喜欢的人，用间接宾语代词表达。
- `el café`：真正主语。
- `gusta`：与单数主语 `el café` 配合。

不能写成以 `yo` 直接作 `gustar` 主语的中文式结构。

### 2. `gusta` 还是 `gustan`

| 真正主语 | 形式 | 例句 | 中文 |
| --- | --- | --- | --- |
| 单数名词 | `gusta` | `Me gusta el café.` | 我喜欢咖啡。 |
| 复数名词 | `gustan` | `Me gustan las manzanas.` | 我喜欢苹果。 |
| 动词原形 | `gusta` | `Me gusta comer ...` | 我喜欢吃…… |

判断时先找“被喜欢的事物／动作”，再决定 `gusta` 或 `gustan`，不能只看中文里的“我、你、他”。

### 3. 间接宾语代词表

| 喜欢的人 | 间接宾语代词 | 单数事物 | 复数事物 |
| --- | --- | --- | --- |
| `yo` | `me` | `me gusta` | `me gustan` |
| `tú` | `te` | `te gusta` | `te gustan` |
| `usted / él / ella` | `le` | `le gusta` | `le gustan` |
| `nosotros / nosotras` | `nos` | `nos gusta` | `nos gustan` |
| `vosotros / vosotras` | `os` | `os gusta` | `os gustan` |
| `ustedes / ellos / ellas` | `les` | `les gusta` | `les gustan` |

这张表中的 `me / te / le / nos / os / les` 是老师资料中的与格／间接宾语代词。它与第 14 课学过的与格表一致。

### 4. 完整强调形式

`a + 重读人称形式` 可以用来明确或强调“是谁喜欢”，但短代词仍然保留：

| 人称 | 强调形式 | 完整结构 |
| --- | --- | --- |
| 我 | `a mí` | `A mí me gusta ... / A mí me gustan ...` |
| 你 | `a ti` | `A ti te gusta ... / A ti te gustan ...` |
| 您 | `a usted` | `A usted le gusta ... / A usted le gustan ...` |
| 他 | `a él` | `A él le gusta ... / A él le gustan ...` |
| 她 | `a ella` | `A ella le gusta ... / A ella le gustan ...` |
| 我们 | `a nosotros / a nosotras` | `A nosotros nos gusta ... / A nosotras nos gustan ...` |
| 你们 | `a vosotros / a vosotras` | `A vosotros os gusta ... / A vosotras os gustan ...` |
| 各位 | `a ustedes` | `A ustedes les gusta ... / A ustedes les gustan ...` |
| 他们 | `a ellos` | `A ellos les gusta ... / A ellos les gustan ...` |
| 她们 | `a ellas` | `A ellas les gusta ... / A ellas les gustan ...` |

注意：`mí` 带重音；`ti` 不带重音。`A ella le gusta ...` 中 `a ella` 可以省略，但 `le` 不能因为省略强调成分而一并删掉。

### 5. 课堂例句和卡点

- `Me gusta el café.`：我喜欢咖啡。
- `Me gustan las manzanas.`：我喜欢苹果。
- `Me gustan mis amigos.`：我喜欢我的朋友们；我独立翻译正确。
- `Me gustan estos mariscos.`：我喜欢这些海鲜；最初把复数主语配成 `gusta`，并忘了 `estos`，提示后完成。
- `A ella le gusta el chocolate.`：她喜欢巧克力。
- `Me gusta comer ...`：我喜欢吃……；第二个动词保持原形，老师明确评价“非常正确”。

| --- | --- | --- |
