## 课中重点与个人卡点

### 1. 正向比较级：`más + 形容词 + que`

- 结构：`A + ser + más + 形容词 + que + B`，表示“A 比 B 更……”。
- `Marta es más inteligente que Ana.`：Marta 比 Ana 更聪明。
  - 主语：`Marta`
  - 谓语：`es`
  - 比较结构：`más inteligente que`
  - 比较对象：`Ana`
- `más` 在本节比较级和最高级中带书面重音。
- `que` 在本节比较结构中连接比较对象，可辅助理解为英语 `than`；其他从句用法以后再学。
- 卡点：曾把 `que` 理解为介词；本节按连接比较对象的词理解。

### 2. 反向比较级：`menos + 形容词 + que`

- `menos` 与 `más` 对照，表示“更少、更不……”。
- 结构：`A + ser + menos + 形容词 + que + B`。
- “他比哥哥更矮”的课堂完整例句中，可靠核心为 `menos alto ... que ...`；姓名、物主形式和亲属词待补充。

### 3. 最高级：定冠词 + `más / menos` + 形容词 + `de`

- 正向最高级：定冠词 + `más` + 形容词 + `de` + 比较范围。
- 反向最高级：定冠词 + `menos` + 形容词 + `de` + 比较范围。
- 四个定冠词已在第 11 课可靠确认：`el / la / los / las`；具体选择要与所指名词的性别和数量配合。
- `de` 在这里引出比较范围，例如“在班级范围中最……”。本节统一使用 `de`，不要混入 `por`。
- 名词在上下文明确时可能省略，因此表面上会看到定冠词直接接 `más / menos`。老师强调这里首先按定冠词理解，不要急于当成代词。
- Marta“班里最聪明……”的完整课堂例句：待补充。

### 4. 比较结构中的 `ser`

- 加入 `más / menos ... que ...` 不会改变 `ser` 原来的使用逻辑。
- 比较人物性质时仍可正常使用 `ser`，如 `Marta es más inteligente que Ana.`。
- 老师用菜品甜度作辅助例子，但完整西语句未可靠转写，不补写。

### 5. 冠词：正式规则与口语学习策略

- 正式规则：冠词与名词存在性别、数量和结构上的配合；本课还提及类似 `todos / todas + los / las + 名词` 的结构，但原例句待补充。
- 老师的学习策略：初学口语偶尔漏冠词，对方往往仍能理解；这不是“冠词可以随意省略”的语法规则。
- 老师提前提到简单过去时与过去未完成时，但本节没有学习其构成、变位或用法。

### 6. 人物描述词汇复习

- `delgado`：瘦的；本次转写为 `Stelgado`，采用第 11 课可靠记录。
- `alegre`：高兴、快乐；`Estoy alegre.`：我很高兴。
- `ahora`：现在、当下，可用于强调当前状态。
- `generoso`：慷慨、大方；本次转写冲突，但第 11 课已可靠确认。本节发音被老师纠正。
- `mayor`：年长、年龄较大的；本次转写为 `maior`，采用第 10—11 课记录。
- `Soy muy simpático y sociable.`：我很友善，而且善于社交。老师明确评价 `Muy bien.`。
- `están separados` 中的 `separados` 已在第 11 课确认；本节最初想机械套用该旧句，老师要求改为自由造句。

### 7. 从背诵转向主动造句

- 老师认为单词可以背，但不主张死记整篇课文；更重视把词重新组合，表达自己真正想说的内容。
- 本节卡点：能识别或复述旧例句，但脱离例句后主动调用词汇、选择正确人称变位时容易卡住。
- 规则动词可借已掌握的 `hablar → habla` 推导第三人称单数，而不是逐个形式孤立死记。
- 描述父亲／母亲时曾混淆第一人称和第三人称单数；本次目标动词原形不可靠，完整变位不补写。

### 8. `mi` 与 `yo`

- `mi`：我的，是放在名词前的物主形容词，例如 `mis amigos`。
- `yo`：我，是主语人称代词；该形式已在第 5 课确认。
- 二者类似英语 `my / I`，语法身份不同，不能互换。
- `mis amigos` 使用 `mis`，因为后面的 `amigos` 是复数。

### 9. `hombre`、`casa` 与 `piso`

- `hombre`：男人、男性，也可依语境表示丈夫。
- `casa`：家、房子。
- `piso`：楼层，也可表示一套住房；虽然本次转写冲突，但该词已在第 8、11 课确认。
- “我的住房在二楼”的完整课堂目标句未可靠保留，不补写。
