## 五、正文后段：参观与旅行

### 1. vamos a + 动词原形

这个句型表示：**我们要／打算做某事**。“动词原形”指还没有按“我、你、他、我们”等人称变化的动词形式，比如 visitar。

**visitar 是一个单词，意思是参观、游览，也可以表示拜访。**把它放进这个句型，就得到 vamos a visitar：我们要去参观／拜访。

AI 巩固例句（不是课文原句）：**Vamos a visitar una pirámide.**（我们要去参观一座金字塔。）

| 部分 | 怎样理解 |
| --- | --- |
| vamos | ir 对应“我们”的变位，前面可以省略 nosotros（我们）。 |
| a | 这个句型中需要保留的连接词。 |
| visitar | 参观，保持动词原形。 |
| una pirámide | 一座金字塔。 |

在这个句型中，**前面的 vamos 已经变位，后面的 visitar 用原形**，所以写 vamos a visitar，不写 vamos a visitamos。

第 4 课的 Vamos a la playa 是“我们去海滩”，a 后接地点；本节这里 a 后接的是动作，不能把两个结构混在一起。以上中文解释于 2026-09-28 根据你的提问补充，不将提问算作新的遗忘记录。
