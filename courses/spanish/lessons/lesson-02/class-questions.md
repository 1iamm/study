# 西班牙语第 2 课｜课中问题

**课程进度：** 已讲到字母 **H / h**；下节课从 H 之后继续。

## 1. r 与 rr

- 词首 `r` 要发多击颤音：`rama, renta, riñe, roto, ruido`。
- 词中 `rr` 也发多击颤音：`perro`。
- `r` 夹在两个元音之间时通常是短促单击音：`cara`；不要读成长颤音。
- `r` 在 `n、l、s` 后、且开始一个音节时，也常发多击颤音：`enredo, alrededor, israelí`。

练习对比：`pero` — `perro`；`cara`（单击 r）。

## 2. 字母与常用表达

| 内容 | 记法 |
| --- | --- |
| K、W | 多见于外来词或外来人名，如 `kilo, kiwi, web, walkman`。 |
| Z | 不是只用于外来词。拉美多数地区读 /s/；西班牙中北部常读 /θ/。跟随老师口音即可。 |
| ya | 基本义是“已经”；`ya está` 才常表示“好了 / 就这样 / 结束了”。 |
| `Perdona.` | “抱歉 / 不好意思 / 劳驾”（对 `tú`）；更正式是 `Perdone.`；“抱歉”也常说 `Perdón.` |
| `No pasa nada.` | “没关系 / 没什么。” |
| `Muy bien.` | “很好。” |
| `Lo he recibido.` | “我收到它了 / 已收到。” |

## 3. 清浊对照

| 清音 | 浊音 | 起步练习 |
| --- | --- | --- |
| `p` | `b / v` | `pa` — `ba`；标准西语中 b 与 v 基本同音。 |
| `t` | `d` | `ta` — `da`。 |
| `c`（a, o, u 前） | `g`（a, o, u 前） | `ca` /ka/ — `ga` /ga/。 |

`b、d、g` 在元音之间常读得较柔和；目前先把 `p/b`、`t/d`、`k/g` 的基本对立读清。

## 4. g 的规则

| 拼写 | 读法提示 | 例子 |
| --- | --- | --- |
| `ga, go, gu` | 硬音 | `gato, goma, gusto` |
| `ge, gi` | 像西语 j 的喉音 | `gente, gira` |
| `gue, gui` | **u 不发音**，读硬 g | `guerra, guitarra` |
| `güe, güi` | `ü` 要发音，读 `gwe, gwi` | `vergüenza, pingüino, güey` |

口诀：`gue/gui` 里 **u 安静**；`güe/güi` 里 **ü 出声**。

## 5. h、x、v、w

- **h 通常不发音**：`hijo` 近似读 `ijo`。`hue-` 中听到的 /w/ 来自 u，不是 h。
- **x 通常读 /ks/**：`examen` 可近似拆成 `ek-sa-men`。`xe` 可以按 /kse/ 理解，但不是常规独立音节规则。
- **v**：与 b 基本同音；`va` 可按 `ba` 的方向练，不读英语 /v/。
- **w**：不能一律读 b；`web, waterpolo` 常接近 /w/，也有词接近 /b/，以老师示范和具体单词为准。
