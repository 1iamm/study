## 课中重点与个人卡点

### 1. 数字

- `0—15` 需要优先单独背诵；老师提供的完整表见[数字参考](/courses/spanish/lessons/lesson-07/materials/numbers-0-99.md)。
- `16—19`：`dieci- + 个位数`，不加 `y`；`dieciséis` 要写重音。
- `20—29`：`veinti- + 个位数`，不加 `y`；`veintidós`、`veintitrés`、`veintiséis` 要写重音。
- `30—99`：`整十数 + y + 个位数`，如 `treinta y uno`。
- `sesenta`（60）与 `setenta`（70）容易混淆。
- `uno` 单独表示“一”；在阳性单数名词前变为 `un`：`un melón`。`dos` 等其他普通数字不作同类变化。
- 老师肯定你的数字朗读整体发音不错；当前重点是能读、能识别，数字拼写不要求全部死记。

### 2. 问职业：`¿A qué se dedica?`

| 形式 | 含义与说明 |
| --- | --- |
| `dedicarse a + 行业／活动` | 从事某行业、领域或活动。 |
| `¿A qué se dedica?` | 您从事什么工作／职业是什么？礼貌问法。 |
| `se dedica` | 您／他／她从事…… |
| `me dedico` | 我从事…… |
| `Me dedico al turismo.` | 我从事旅游业。 |

- `dedicarse` 是动词原形；自复代词 `se` 连在原形后。
- 变位后，自复代词放在变位动词前并分开写：`se dedica`、`me dedico`。
- `dedicarse a` 后接行业、领域或活动；具体职业更适合用 `Soy + 职业`。
- 卡点：容易把 `se` 当词尾、忘记代词会随人称变化，或认为变位后仍应连写。

### 3. `a + el = al`

- `Me dedico a el turismo.` 必须写作 `Me dedico al turismo.`。
- `al` 是 `a + el` 的缩合，口语和书面语都必须遵守。
- `el` 是阳性定冠词；注意与带重音的 `él`（他）区分。

### 4. 工作、学习与简略回答

| 句子 | 含义与说明 |
| --- | --- |
| `¿Dónde trabajas?` | 你在哪里工作？`trabajas` 是第二人称单数。 |
| `¿Y dónde trabaja?` | 那么，您在哪里工作？`trabaja` 与 `usted` 对应。 |
| `En un restaurante mexicano.` | 在一家墨西哥餐厅。口语中的简略回答；完整语境已明确时可省略动词。 |
| `¿Qué haces?` | 你做什么／你在干什么／你是做什么的？含义取决于语境。 |
| `¿Trabajas?` | 你工作吗／你上班了吗？ |
| `No, no trabajo. Estudio.` | 不，我不工作。我在学习。课堂完整对话顺序仍有部分待补充。 |
| `¿Qué estudias?` / `Medicina.` | 你学什么？／医学。 |

- 初学者自己造句时，形容词通常先放在名词后：`restaurante mexicano`。
- 卡点：`trabajo / trabajas / trabaja / trabajamos` 和 `estudio / estudias` 的人称形式容易混淆。

### 5. 地址、方向、居住与楼层

- `avenida`（大道）和 `paseo`（步道、散步道或步行街一类道路）本节不要求背诵。
- `paseo` 的发音被纠正：`a、e、o` 都是强元音，强元音相邻不能随意合并；老师确认纠正后的朗读没有问题。
- `izquierda`：左／左边；你的朗读得到老师肯定。
- `derecha`：右／右边。
- `vivir`：居住、生活；本阶段先记“居住”。`vivo`：我住／我居住。
- `sótano uno / dos / tres`：地下 1／2／3 层。
- `planta baja`：地面层、底层；在西班牙楼层称呼中，地面层通常不按“一层”计算，其上一层再开始编号。

## 本节反馈与复习优先级

1. 先背 `0—15`，再通过规律读出 16—99。
2. 重点不漏写四个数字的重音：`dieciséis`、`veintidós`、`veintitrés`、`veintiséis`。
3. 用自己的话讲清：`dedicarse → se dedica / me dedico`，以及 `a + el = al`。
4. 复习 `paseo` 的强元音与 `izquierda` 的朗读。
