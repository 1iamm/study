# 西班牙语第 4 课｜音节、自然重音与阴阳性

> **材料来源：** 本课讲义《西班牙语音节拆分规则》与课后作业照片。此次 Record 可能未成功转写，因此不补写无法确认的老师讲解。

## 模块一：音节拆分规则

### 1. 强弱元音

- 强元音：`a、e、o`。
- 弱元音：`i、u`。
- 元音是音节的核心；后续先判断相邻元音是“合在一起”还是“拆开”。

例：`casa → ca-sa`；`ciudad → ciu-dad`。

### 2. 无重音弱元音通常不拆

`强+弱`、`弱+强`、`弱+弱` 通常构成二重元音，留在同一音节。

- `pueblo → pue-blo`
- `causa → cau-sa`
- `ciudad → ciu-dad`

### 3. 两个强元音相遇要拆开

`a、e、o` 相邻时，通常各自构成音节。

- `caos → ca-os`
- `poeta → po-e-ta`
- `pelear → pe-le-ar`

> [!IMPORTANT]
> **个人卡点／易忘项｜规则 4：带重音的弱元音 `í / ú` 会强制拆开。**
> 这是优先复习项。

### 4. 带重音的弱元音 `í / ú` 会强制拆开

弱元音带重音时，不再与相邻元音合成二重元音。

- `Raúl → Ra-úl`
- `país → pa-ís`
- `María → Ma-rí-a`

对比：`también → tam-bién`；重音在强元音 `é` 上，`ié` 仍不拆。

### 5. 一个辅音夹在两个元音之间：辅音归后

- `pero → pe-ro`
- `casa → ca-sa`

### 6. 两个辅音：通常从中间拆；常见连缀不拆

普通情况：`acto → ac-to`。

下列连缀留在后一音节：`pr、pl、br、bl、cr、cl、dr、gr、gl、fr、fl、tr`。

- `abrir → a-brir`

### 7. `ch / ll / rr` 不从中间拆

它们在这里按一个辅音组合处理。

- `perro → pe-rro`
- `llave → lla-ve`
- `chico → chi-co`

### 8. 三重元音通常不拆

常见结构是 `弱+强+弱`。

- `Uruguay → U-ru-guay`
- `buey → buey`

### 9. `h` 不发音，但夹在元音间仍分开音节

- `búho → bú-ho`
- `ahora → a-ho-ra`

> [!IMPORTANT]
> **个人卡点／易忘项｜规则 10：`qu` 在 `que / qui` 中不可拆。**
> 这是优先复习项。

### 10. `qu` 在 `que / qui` 中不可拆

- `quien → quien`
- `aquí → a-quí`
- `cheque → che-que`

不要写成 `a-q-uí`。

## 模块二：单词自然重音（最高优先级）

这是**独立于音节拆分**的模块：先拆音节，再判断哪一个音节重读。

1. 词尾是五个元音 `a、e、i、o、u`，或 `n、s`：自然重音通常在倒数第二音节。
   - `casa → cá-sa`
   - `hablas → há-blas`
2. 词尾是其他辅音：自然重音通常在最后一个音节。
   - `español → es-pa-ñol`
   - `ciudad → ciu-dad`
   - `Uruguay → U-ru-guay`
3. 单词写有重音符号时，以写出的重音符号为准。
   - `inglés → in-glés`
   - `aquí → a-quí`
   - `México → Mé-xi-co`

> 本笔记中的 `cá-sa`、`U-ru-guay` 是朗读标记；不要因此改写原单词拼写。

## 模块三：阴阳性基础判断

### 起步规则

- 多数 `-a` 结尾名词为阴性：`la casa`。
- 多数 `-o` 结尾名词为阳性：`el libro`。
- 形容词和国籍词通常要与人物或名词配合：`mexicano / mexicana`，`español / española`。

### 先记住的例外

- `el problema`：以 `-a` 结尾，但为阳性。
- `la mano`：以 `-o` 结尾，但为阴性。

结论：`-a / -o` 是快速判断法，不是绝对规则；遇到新名词要连同冠词 `el / la` 一起记。
