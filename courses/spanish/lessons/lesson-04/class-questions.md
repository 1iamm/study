## 课中重点与个人卡点

### 1. 拼读、重音与连读

- `Perú` 的发音得到老师肯定：重音清楚、读法标准。
- `aeropuerto` 的拼读技巧也得到肯定。
- `Suiza` 初次读错；`Austria` 和 `Australia` 容易混淆。
- `Madrid`、`Austria`、`Australia` 容易受英语发音影响；朗读时要回到西语的读音规则。
- `Estados Unidos` 后接以元音开头的词时可以自然连读；`Ecuador`、`Perú` 这类词不按这一方式连读。

### 2. 基础交际

| 表达 | 用法 |
| --- | --- |
| `Buenos días.` | 早上好／上午好；本课按 12 点前使用理解。 |
| `Me llamo ...` / `Yo me llamo ...` | 我叫……；`yo` 可以省略。 |
| `¿Cómo se llama?` | 您怎么称呼？用于礼貌询问姓名。 |
| `Mucho gusto.` | 很高兴认识你。 |

- 西语问句要有前后问号：`¿ ... ?`。
- 疑问词 `cómo` 带重音符号；它与不带重音的 `como` 要区分，但本课未展开后者的具体用法。

### 3. 为什么 `yo` 可以不说

- 西语动词的变位本身能表达说话人，因此主语代词常省略。
- 本课先记住以下形式，不要求展开复杂语法：

| 人称 | 形式 |
| --- | --- |
| `yo` | `me llamo` |
| `tú` | `te llamas` |
| `él / ella / usted` | `se llama` |

### 4. 冠词与阴阳性

- `el / la` 是定冠词，分别配阳性／阴性名词；`un / una` 是不定冠词，也随名词阴阳性变化。
- 形容词通常也要和名词的阴阳性配合；动词不按这一规则变化。
- 入门阶段可先记：多数 `-o` 结尾名词为阳性，多数 `-a` 结尾名词为阴性；这只是约 90% 适用的快速判断法。
- 例外：`la mano`、`la radio` 虽以 `-o` 结尾，但为阴性。
- 学新名词时尽量连冠词一起记：`la leche`，不要只记 `leche`。
- `¿Qué es esto?` 的回答尽量使用完整名词词组，例如 `la leche`。
- 本节只讲阴阳性和单数基础；后续改为遇到一个记一个，不一次性记大量词尾规则。

### 5. 职业、国家与海边表达

- `ingeniero de la empresa de internet`：互联网公司的工程师。`de` 用于连接两个名词。
- `el mar`（海）、`la playa`（海滩／海边）、`la costa`（海岸）、`la costumbre`（习惯）。
- `Vamos a la playa.`：我们去海滩吧。现阶段整体记忆即可；`a` 表示方向，`vamos` 是第一人称复数形式。
