## 课中重点与个人卡点

### 1. `en`、`por` 与 `por internet`

- `en mi casa`：在我家；本课将 `en` 作为地点介词复习。
- `por internet`：通过互联网、通过网络；这里的 `por` 表示方式或途径。
- 句子：`Vendemos viajes por internet.`（我们通过互联网销售旅游产品。）
- `vendemos` 来自 `vender`，表示“我们销售”；`viajes` 是 `viaje` 的复数。
- 卡点：曾把整句理解为“在旅游网站上购买”；也没有立即认出 `vendemos` 是动词变位。
- 本课对 `en / por` 的地点范围界限说明不够清晰，相关细节保留为待补充；不要仅凭“城市或国家”机械选择。

### 2. 数字与重音

| 数字 | 西班牙语 | 要点 |
| --- | --- | --- |
| 22 | `veintidós` | 连写，带重音。 |
| 23 | `veintitrés` | 连写，带重音。 |
| 26 | `veintiséis` | 连写，带重音；不能因 `seis` 单独无重音就漏写。 |
| 48 | `cuarenta y ocho` | 30 以上的非整十数用 `y` 连接。 |
| 50 / 60 / 66 | `cincuenta / sesenta / sesenta y seis` | 整十和组合数字需加快反应。 |

- 二十几是一个完整单词，不拆成两个词。
- 卡点：易忘 40、50 等整十数；对 20 多数字的连写和重音不够熟悉。

### 3. 名称、自我介绍与省略主语

- `¿Cómo se llama?` 可按语境问“它／公司／您叫什么名字？”。
- `¿Cómo te llamas?`：你叫什么？`Me llamo Claudio.`：我叫 Claudio。
- `Funciona bien.`：它运转良好。在课文中主语是前文的 `la empresa`，因为上下文和第三人称单数 `funciona` 已足以判断，所以可省略主语。
- `bien` 是副词，修饰 `funciona`；`muy bien` 是“很好”。
- 卡点：对 `se llama`、`me llamo` 中代词的作用不清楚；看到省略主语的句子时不易马上找到主语。

### 4. `tener` 的变位与年龄

| 人称 | `tener` 现在时 | 中文 |
| --- | --- | --- |
| yo | `tengo` | 我有 |
| tú | `tienes` | 你有 |
| él / ella / usted | `tiene` | 他／她／您有 |
| nosotros / nosotras | `tenemos` | 我们有 |
| vosotros / vosotras | `tenéis` | 你们有 |
| ellos / ellas / ustedes | `tienen` | 他们／她们／各位有 |

- 年龄使用“`tener` 的变位 + 数字 + `años`”：`Tengo veintiocho años.`（我 28 岁。）
- `Mi mamá tiene cincuenta años.`／`Mi papá tiene sesenta años.`
- 卡点：只熟悉 `tengo`；造年龄句时易漏掉 `tiene`，且数字和 `años` 的发音、重音不稳。

### 5. 复合句与 `trabajar`

- 同一主语的两个分句可用 `y` 连接，第二个分句可省略重复主语：`Mi papá tiene cincuenta años y vive en Shanghái.`
- `trabajar` 是规则 `-ar` 动词：

| 人称 | 变位 |
| --- | --- |
| yo | `trabajo` |
| tú | `trabajas` |
| él / ella / usted | `trabaja` |
| nosotros / nosotras | `trabajamos` |
| vosotros / vosotras | `trabajáis` |
| ellos / ellas / ustedes | `trabajan` |

- `trabajáis` 要写重音。卡点：会把 `hablar` 和 `trabajar` 的形式混淆，后面三种复数形式反应较慢。

### 6. 常用搭配与词义随冠词变化

- `Necesitamos un poco de capital.`：我们需要一些资金。
- `un poco de + 名词`：一点、一些……。
- `el capital`：资金、资本；`la capital`：首都。词义随冠词阴阳性变化，不靠大小写区分。
- `tener contacto con ...`：与……有联系／保持联系；其中 `con` 是“和、与”，与 `sin`（没有、不带）相对。
- `necesitar` 的“我们需要”形式在本次转写中不清晰，不以转写猜写；上面的完整句以 Record 中可明确识别的课文句为准。

### 7. 发音与本课词汇

- `internet` 不按英语方式读；词尾 `t` 要清楚，元音也不要套用英语读法。
- `funciona` 要读得干脆，避免多余的滑音或鼻音。
- `negro` 在课堂中用于辅助发音；`africano` 表示非洲人／非洲的。
- 卡点：`internet` 易读成英语发音，且难以听出自己发音前后的差别。

### 8. 文化词汇

- `castellano`：卡斯蒂利亚语，也是“西班牙语”的一种称呼。
- `paella`：西班牙饭类菜肴；常译为“西班牙海鲜饭”，但传统瓦伦西亚版本不一定含海鲜。
- `media`：一半、半份；`vino`：葡萄酒；`tapas`：一类西班牙小吃，不是单一菜名。
- 课堂中关于价格、食堂及地区饮食的内容是老师个人经历分享，不作为统一事实或价格标准。
