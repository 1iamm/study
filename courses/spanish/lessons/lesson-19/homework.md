## 建议背诵清单

> 以下按老师本节强调和已可靠确认的拼写整理，便于执行作业；不是老师逐项口述的完整指定清单。

### 优先背诵

- 状态：`cansado / cansada`、`agotado / agotada`
- 食品：`fruta`、`marisco`、`arroz`、`verdura`、`aceite de oliva`、`pollo`、`pescado`、`sal`、`carne`、`gambas`
- 场景：`sala`
- 计量：`un litro / dos litros`、`una barra de pan`、`medio kilo`、`gramo / gramos`、`lata`、`bolsa`、`una docena`
- 饮品和文化：`vino tinto`、`vino blanco`、`gazpacho`、`mate`、`frijoles`、`sopa de frijoles`、`sangría`

### 认识并建立区别

- `pollo` 是鸡肉；活鸡、公鸡、母鸡的课堂词形待确认。
- `pescado` 是作为食物的鱼；活鱼的课堂词形待确认。
- `gamba / gambas` 与 `camarón` 都表示虾；老师按西班牙与拉美的使用倾向作了对比。
- `vino tinto` 是红葡萄酒，`vino blanco` 是白葡萄酒。
- `cansado` 是累，`agotado` 程度更强。

## 旧内容加强

1. `mil / dos mil`：累计第 2 个遗忘课次，本节两次千位回答不稳；计划正确复现 4 次。
2. `a ver / vamos a ver`：本节第一次明确记错；计划正确复现 3 次。
3. `poder` 变位：本节已完成 1 次正确复习，剩余 2 次。
4. `bolsa`：本节已完成 1 次正确复习，剩余 1 次。
5. `carne`：本节没有足够证据结算，沿用第 15 课队列，剩余 3 次。

## 5 分钟自查

1. 不看答案写出：1000、2000、10,000。
2. 说出 `ver / a ver / vamos a ver` 的区别。
3. 用 `¿Puedo ...?` 说一句购物请求。
4. 分别说出鸡肉、食用鱼、肉类统称。
5. 说出半公斤、一条面包、一打。
6. 说出红葡萄酒、白葡萄酒。

### 自查答案

1. `mil / dos mil / diez mil`。
2. `ver` 是“看”的原形；`a ver` 是“看看／让我看看”；`vamos a ver` 是“我们来看一下”。
3. 例如：`¿Puedo ver ese reloj?`
4. `pollo / pescado / carne`。
5. `medio kilo / una barra de pan / una docena`。
6. `vino tinto / vino blanco`。
