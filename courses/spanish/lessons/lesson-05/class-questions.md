# 西班牙语第 5 课｜一般现在时动词变位与基础交流

## 课程进度

- 学习主格人称代词与一般现在时动词变位。
- 重点掌握两个动词：规则 `-ar` 动词 `hablar`，以及系动词 `ser`。

## 课中重点与个人卡点

### 1. 朗读时要读出语气

- `¡Hablas muy bien español!` 是带感叹色彩的表达；句末自然下降，不能读得平直。
- `¿Y qué lenguas hablas?` 要有明确的问句语气。
- 老师肯定：你的发音整体很好；第二次读感叹句时的感觉更自然。

### 2. 主格人称代词

| 人称 | 含义 | 说明 |
| --- | --- | --- |
| `yo` | 我 | 动词变位能体现人称时，常省略。 |
| `tú` | 你 | 非正式单数“你”。 |
| `él / ella / usted` | 他／她／您 | `usted` 虽表示“您”，动词用第三人称单数形式。 |
| `nosotros / nosotras` | 我们 | 有男性或混合群体用 `nosotros`；全女性用 `nosotras`。 |
| `vosotros / vosotras` | 你们 | 主要用于西班牙；全女性用 `vosotras`。 |
| `ellos / ellas / ustedes` | 他们／她们／诸位 | `ustedes` 是复数“您／你们”；本课未细分各拉美地区的实际差异。 |

**最重要的区分：**代词、名词、冠词和形容词可能有阴阳性；动词只随人称与单复数变位，不随性别变位。

### 3. `tú`、`usted`、`vosotros` 与 `ustedes`

- `tú` 是日常的“你”；`usted` 用于相对正式或保持距离的称呼。
- 老师说明，在西班牙即使面对老师也常直接用 `tú`，并可直接称呼对方名字。
- 西班牙常用 `tú / vosotros`；老师概括拉美地区通常不用 `vosotros`，更常见 `usted / ustedes`。本课未进一步细分国家差异。

### 4. 一般现在时：`hablar` 的完整变位

老师讲义确认的变位表：

| 人称 | 变位 | 中文 |
| --- | --- | --- |
| `yo` | `hablo` | 我说 |
| `tú` | `hablas` | 你说 |
| `él / ella / usted` | `habla` | 他／她／您说 |
| `nosotros / nosotras` | `hablamos` | 我们说 |
| `vosotros / vosotras` | `habláis` | 你们说（西班牙本土） |
| `ellos / ellas / ustedes` | `hablan` | 他们／她们／诸位说 |

- 规则 `-ar` 动词目前先记：`-o / -as / -a / -amos / -áis / -an`。
- 动词原形主要有 `-ar`、`-er`、`-ir` 三类；本节只讲 `-ar`。
- 第三人称单数 `habla` 可对应 `él`、`ella`、`usted`，若上下文不清楚，需要补出代词或名字避免歧义。
- `habláis` 的重音在 `á`；这也是老师在课上特别纠正的重点。

### 5. `ser` 的完整变位

老师讲义确认的变位表：

| 人称 | 变位 | 中文 |
| --- | --- | --- |
| `yo` | `soy` | 我是 |
| `tú` | `eres` | 你是 |
| `él / ella / usted` | `es` | 他／她／您是 |
| `nosotros / nosotras` | `somos` | 我们是 |
| `vosotros / vosotras` | `sois` | 你们是（西班牙本土） |
| `ellos / ellas / ustedes` | `son` | 他们／她们／诸位是 |

- `ser` 是不规则动词；现阶段先完整记忆变位。
- `Soy chino.` 是“我是中国人”；`Soy de China.` 是“我来自中国”。
- `de` 在 `Soy de China.` 中可理解为“来自／from”，但不等于只会表示这一种关系。

### 6. 本节核心问答

| 句子 | 含义与用法 |
| --- | --- |
| `¿De dónde eres?` | 你来自哪里？`dónde` 要带重音，`de` 不能省略。 |
| `Soy de China.` | 我来自中国；用国家名称回答。 |
| `Sí, soy chino.` | 是的，我是中国人。 |
| `¿Y qué lenguas hablas?` | 你会说什么语言？`y` 可作承接词，也可省略。 |
| `Hablo español.` | 我说西班牙语；`yo` 可省略。 |
| `un poco de inglés` | 一点英语；`un poco de` 后的 `de` 不能省略。 |
| `Ellas son de China.` | 她们来自中国；课堂造句正确。 |

### 7. 易混点

- `él`（他）有重音；`el` 是阳性定冠词，相当于英语 `the`，不是“他／他的”。
- `China` 是中国这一国家名称；`chino` 用于“中国人／中国的”相关表达。
- `España` 是西班牙这一国家名称；`español` 要结合句子判断为西班牙语、西班牙人或西班牙的。
- `bien` 修饰动作，表示“好地”；`muy` 修饰 `bien`，`muy bien` 程度更强。实际交流中也要结合语气理解。
