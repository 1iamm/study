### 练习题原文

> 只转换文档文字，保留题目空格；当前不预填答案。题面中的西班牙语和中文均按老师文档记录。

1. `Yo compro un libro para Ana. → Yo ____ compro.`（我给她买这本书）
2. `Tú ves a mí. → Tú ____ ves.`（你看见我）
3. `Él da una manzana a nosotros. → Él ____ da.`（他给我们一个苹果）
4. `Nosotros compramos unas flores para ti. → Nosotros ____ compramos.`（我们给你买这些花）
5. `Vosotros lleváis los cuadernos a los niños. → Vosotros ____ lleváis.`（你们给孩子们带这些本子）
6. `Ella conoce a él. → Ella ____ conoce.`（她认识他）
7. `Yo muestro la foto a vosotros. → Yo ____ muestro.`（我给你们看这张照片）
8. `Tú das el bolígrafo a ella. → Tú ____ das.`（你把这支笔递给她）
9. `Él busca a nosotros. → Él ____ busca.`（他找我们）
10. `Nosotros traemos unas bebidas para ti. → Nosotros ____ traemos.`（我们给你带来一些饮料）
11. `Vosotros enviáis las cartas a ellos. → Vosotros ____ enviáis.`（你们给他们寄这些信）
12. `Yo ayudo a ti. → Yo ____ ayudo.`（我帮你）
13. `Ella vende el coche a mí. → Ella ____ vende.`（她把这辆车卖给我）
14. `Tú prestas los libros a ellas. → Tú ____ prestas.`（你把书借给她们）
15. `Él enseña la palabra a vosotros. → Él ____ enseña.`（他教你们这个单词）

## 3. 当前自查清单

> 这部分用于等待正式题目期间自查，不额外视为老师布置的新作业。

- [ ] 能判断“给什么”是直接宾语、“给谁”是间接宾语。
- [ ] 能写出宾格代词：`me, te, lo/la, nos, os, los/las`。
- [ ] 能写出与格代词：`me, te, le, nos, os, les`。
- [ ] 能记住两个代词同时出现时“先与后宾”。
- [ ] 能把 `le/les + lo/la/los/las` 正确改成 `se + lo/la/los/las`。
- [ ] 能解释 `Te amo.` 中的 `te` 是直接宾语。
- [ ] 能正确说：`Le doy un libro.`、`Lo doy a mi padre.`、`Se lo doy.`。
