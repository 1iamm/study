## 课中重点与个人卡点

### 1. 序数词与楼层

| 序数词 | 西班牙语 | 重点 |
| --- | --- | --- |
| 第一 | `primero` | 阳性单数名词前变 `primer`。 |
| 第二 | `segundo` |  |
| 第三 | `tercero` | 阳性单数名词前变 `tercer`。 |
| 第四 | `cuarto` | 不要和 `cuatro`（四）混淆。 |
| 第五 | `quinto` | 不要和 `quince`（十五）混淆。 |

- `primer piso`：第一层；`primera planta`：第一层。
- `piso` 可表示楼层，也可表示一套住宅；`planta` 表示楼层。
- 卡点：对 `primer / tercer` 省略 `-o`、`piso / planta` 的不同用法不熟悉。

### 2. 住址与 `vivir`

| 句子／词汇 | 含义与说明 |
| --- | --- |
| `¿Dónde vives?` | 你住在哪里？ |
| `Vivo ...` | 我住在…… |
| `¿Dónde vive usted?` | 您住在哪里？ |
| `En la calle de la Libertad.` | 在自由街；口语中可省略已知的谓语。 |
| `número` | 数字、号码、门牌号。 |

- `vivo / vives / vive` 分别表示我住／你住／他、她、您住。
- 正式表达或分析句子结构时要注意完整谓语；口语中已知上下文可以只回答地点。
- `la calle de la Libertad` 中，`de` 连接两个名词；不能简单按英语词序直接并列。
- 卡点：曾把 `vives` 当成“我住”，也不熟悉街道名称加门牌号的顺序。

### 3. `-ar` 动词和常用回应

- `mejorar`：改善、提升；`mejoro`：我改善／提升。规则：常规 `-ar` 动词第一人称单数通常为 `-o`。
- `Muchas gracias.`：非常感谢；`De nada.`：不客气；`No pasa nada.`：回应道歉或小意外时的“没关系”。
- `Nada.` 单独使用有时可能显得冷淡；`De nada.` 与 `No pasa nada.` 不要混用。
- `mucho` 和 `muy` 不是同一个词的变形；`muy` 只能作副词。`muchas gracias` 中 `muchas` 与阴性复数 `gracias` 配合。

### 4. 手机、邮箱与公司介绍

| 词汇 | 含义与说明 |
| --- | --- |
| `móvil` | 手机；西班牙常用。 |
| `celular` | 手机；拉丁美洲常用。 |
| `arroba` | `@` 符号。 |
| `guion / guion bajo` | 短横线 `-`／下划线 `_`。 |
| `agencia de viajes` | 旅行社、旅游代理机构。 |
| `virtual` | 虚拟的、线上的；注意判断它具体修饰哪个名词。 |

- `Soy programador.`：我是程序员。老师确认表达正确。
- `tener` 是不规则动词：`tengo, tienes, tiene, tenemos, tenéis, tienen`。
- `jefe / jefa` 是上司、负责人或老板；`gerente` 更偏具体的经理职位。

### 5. 非重读物主形容词（前置）

讲义规则：放在名词前、不重读，不能单独使用；主要按**被修饰名词**的单复数变化，`nuestro / vuestro` 系列还要配合名词阴阳性。

| 拥有者 | 阳单 | 阴单 | 阳复 | 阴复 |
| --- | --- | --- | --- | --- |
| `yo` | `mi` | `mi` | `mis` | `mis` |
| `tú` | `tu` | `tu` | `tus` | `tus` |
| `él / ella / usted` | `su` | `su` | `sus` | `sus` |
| `nosotros/as` | `nuestro` | `nuestra` | `nuestros` | `nuestras` |
| `vosotros/as` | `vuestro` | `vuestra` | `vuestros` | `vuestras` |
| `ellos / ellas / ustedes` | `su` | `su` | `sus` | `sus` |

例：`mi libro`（我的书）、`mis flores`（我的花）、`nuestra casa`（我们的家）、`vuestros zapatos`（你们的鞋）。

- `su / sus` 可对应他、她、您、他们／她们／各位的，须靠上下文判断拥有者；单复数取决于后面的名词。
- 拉美地区通常用 `ustedes`，相应使用 `su / sus`，不常用 `vuestro`。
- 课堂练习：`nuestro jefe`、`sus jefes` 都答对。

### 6. 重读物主形容词（后置）

讲义规则：通常放在名词后，用于强调归属或对比；形式按被修饰名词的阴阳性和单复数变化。

| 拥有者 | 阳单 | 阴单 | 阳复 | 阴复 |
| --- | --- | --- | --- | --- |
| `yo` | `mío` | `mía` | `míos` | `mías` |
| `tú` | `tuyo` | `tuya` | `tuyos` | `tuyas` |
| `él / ella / usted` | `suyo` | `suya` | `suyos` | `suyas` |
| `nosotros/as` | `nuestro` | `nuestra` | `nuestros` | `nuestras` |
| `vosotros/as` | `vuestro` | `vuestra` | `vuestros` | `vuestras` |
| `ellos / ellas / ustedes` | `suyo` | `suya` | `suyos` | `suyas` |

- `Mi casa es pequeña.`：普通陈述“我的房子很小”。
- `La casa mía es pequeña.`：强调“我家的那套房子”。
- 讲义例：`el coche mío`、`las amigas tuyas`。后置形式构成名词词组时，讲义要求前面搭配相应定冠词。
- `¿Es mío?` 中 `mío` 单独替代名词，是物主代词；`Las fotos antiguas son mías.` 也是同类用法。
- 初期约 95% 日常情况优先使用前置形式；“重读”是语法名称，不等于必须刻意加重发音。

### 核心知识与句型

| 自测问题 | 标准答案 |
| --- | --- |
| `vivir` 的“我住／你住／您住”怎么说？ | `vivo / vives / vive`。 |
| 20—29 与 30 以上的数字怎样构成？ | 21—29：`veinti- + 个位数`，不加 `y`；31 以上：整十数 + `y` + 个位数。 |

| `hasta luego` 和 `hasta mañana` 的区别？ | 前者是通用再见；后者用于明确明天会再见。 |
