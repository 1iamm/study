## 优化后的课堂笔记

### 1. r 与 rr：重点

- **词首 r** 要发多击颤音：`rama, renta, riñe, roto, ruido`。
- **词中 rr** 也发多击颤音：`perro`。
- `r` 夹在两个元音之间时通常是短促的单击音：`cara`，不要读成长颤音。
- `r` 在 `n、l、s` 后、且开始一个音节时，也常发多击颤音：`enredo, alrededor, israelí`。

练习对比：`cara`（短一下）— `carra`（长颤，实际少见）；`pero` — `perro`。

### 2. 字母与常用表达

| 内容 | 更准确的记法 |
| --- | --- |
| K、W | 多见于外来词或外来人名，如 `kilo, kiwi, web, walkman`。 |
| Z | **不是**只用于外来词。拉美多数地区读 /s/；西班牙中北部常读 /θ/（近似英语 *think* 的 th）。跟随老师的口音即可。 |
| ya | 基本义是“已经”；常见 `ya está` 才是“好了 / 就这样 / 结束了”。 |
| `Perdona.` | “抱歉 / 不好意思 / 劳驾”（对 `tú`）；更正式可说 `Perdone.`；名词式“抱歉”常说 `Perdón.` |
| `No pasa nada.` | “没关系 / 没什么。” |
| `Muy bien.` | “很好。” |
| `Lo he recibido.` | “我收到它了 / 已收到。” |

### 3. 清浊：先建立对照

| 清音 | 浊音 | 起步记法 |
| --- | --- | --- |
| `p` | `b / v` | `pa` 对 `ba`；标准西语中 **b 与 v 基本同音**。 |
| `t` | `d` | `ta` 对 `da`。 |
| `c`（在 a, o, u 前） | `g`（在 a, o, u 前） | `ca` /ka/ 对 `ga` /ga/。 |

补充：`b、d、g` 在元音之间常会读得更柔和；现阶段先把 `p/b`、`t/d`、`k/g` 的基本对立读清即可。

### 4. g 的规则：本课最容易混淆的部分

| 拼写 | 读法提示 | 例子 |
| --- | --- | --- |
| `ga, go, gu` | g 的硬音：`ga, go, gu` | `gato, goma, gusto` |
| `ge, gi` | 像西语 `j` 的喉音：`he, hi`（实际音色随地区不同） | `gente, gira` |
| `gue, gui` | **u 不发音**，读 `ge, gi` 的硬音 | `guerra, guitarra` |
| `güe, güi` | `ü` 表示 **u 要发音**，读 `gwe, gwi` | `vergüenza, pingüino, güey` |

口诀：`gue/gui` 里 **u 安静**；`güe/güi` 里 **ü 出声**。

### 5. h、x、v、w：纠正易混点

- **h 通常不发音**：`hijo` 读作近似 `ijo`，`hacer, hemos, hora` 也是如此。注意 `hue-` 中听到的 /w/ 来自 `u`，不是 h。
- **x 通常读 /ks/**：`examen` 可近似读 `ek-sa-men`；所以 `xe` 可拆作 /kse/，但它不是一个需要单独死记的常规音节规则。少数词和专名有例外。
- **v**：在标准西语中与 **b 基本同音**，所以 `va` 可按 `ba` 的方向练；不要按英语 v 去咬唇。
- **w**：来源较多，不要一律按 b 读；在 `web, waterpolo` 一类词常接近 /w/，也有词接近 /b/。按老师示范和具体单词记。
