# 西班牙语课

每节课使用一个独立目录，并包含以下核心文件：

```text
lessons/lesson-XX/
├── class-questions.md  # 课中问题、知识点、待补充信息
├── homework.md         # 课后作业、练习计划、自查清单
└── materials/          # 本课讲义、图片等辅助材料（如有）
```

所有课程词汇统一维护在 [vocabulary.md](vocabulary.md)。文件按课次分区；每个词或短句标明学习课次，并在需要时补充课堂语境下的用法说明。不将只用于发音示范、但未讲词义的例词混入词汇表。

从第 7 课起，每份 `class-questions.md` 末尾增加“艾宾浩斯复习（短清单）”，分为两层：3—5 个之前学过、最影响后续课程的核心知识／句型，以及 6—10 个对应的旧单词或短句。每一项必须写成“自测问题 + 标准答案”，不能只列题纲。建议复习节点为当天、次日、第 3 天和第 7 天；不额外设为老师作业，也不堆入整课全部内容。
