# 西班牙语总词汇表

> 仅收录课堂中已明确学到或已明确说明语义的单词、短句与表达。各课模块按课次倒序排列，最新一课插在最前；不将仅用于发音示范、但未讲词义的例词混入本表。
>
> 第 2—14 课保留原有三列格式。从第 15 课起改用七列：`单词／短句｜语义｜用法与说明｜状态｜首次学习｜遗忘轨迹／本节表现｜复习安排`。状态区分“新词·普通／重点／核心”“旧词·记得”“旧词·遗忘”。旧词遗忘必须写清累计第几次、此前遗忘课次和本节内部重复次数；首次学习与历史遗忘课次由 Codex 查询旧课记录后填写，不能由 Record 猜测。
>
> 复习安排：新普通词至少进入后续 1 次复习，新重点／核心词至少 2 次；旧词第 1／2／3／4 次及以上遗忘，分别安排后续 2／3／4／5 次复习。高频、核心或会阻碍后续学习的内容增加 1 次，最多 5 次；累计第 4 次及以上遗忘时，连续两次回答正确后才能退出重点队列。同一词在同一节课反复忘记只增加一次累计遗忘课次，但要记录本节重复次数。`复习安排` 同时填写“重要性；计划 N 次；已正确 N 次；待 N 次”；仅生成题目不算完成，后续实际回答正确才结算，答错则新增遗忘课次并重新计算。

| `pareja` | 伴侣、另一半；一对。 | 语法上是阴性名词，可指男性或女性伴侣；不要因自然性别改成 `parejo`。 |

### 前置物主形容词复习表

| 拥有者 | 阳性单数名词 | 阴性单数名词 | 阳性复数名词 | 阴性复数名词 |
| --- | --- | --- | --- | --- |
| 我 `yo` | `mi` | `mi` | `mis` | `mis` |
| 你 `tú` | `tu` | `tu` | `tus` | `tus` |

| `China / España` | 中国／西班牙。 | 国家名称；不要与 `chino`、`español` 混淆。 |
| `español` | 西班牙语；西班牙人；西班牙的。 | 具体意思依据句子判断；本节用于 `Hablo español.`。 |
| `¿De dónde eres?` | 你来自哪里？ | `dónde` 带重音；问句中的 `de` 不能省略。 |
| `dónde` | 哪里。 | 本节作为特殊疑问词使用，带重音。 |
| `¿Y qué lenguas hablas?` | 你会说什么语言？ | `y` 用于承接，也可省略；要读出问句语气。 |
| `lengua` | 语言。 | 本课在问句中使用复数 `lenguas`。 |
| `Hablo español.` | 我说西班牙语。 | `yo` 可省略。 |
| `un poco de` | 一点…… | 固定结构，后接名词时 `de` 不能省略。 |
| `un poco de inglés` | 一点英语。 | 用于表达语言能力。 |
| `bien / muy bien` | 好地／很好、非常好。 | `bien` 修饰动作；`muy` 修饰 `bien`。具体语气还要结合场景。 |
| `él / el` | 他／阳性定冠词。 | `él` 有重音，表示“他”；`el` 相当于英语 `the`。 |
| `Ellas son de China.` | 她们来自中国。 | 课堂造句，老师确认正确。 |
