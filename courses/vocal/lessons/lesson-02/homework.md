# 声乐第 2 课｜课后作业

## 老师明确布置的作业

1. 课下继续练习今天课上的基础发声练习。
2. 继续练习《依然爱你》今天讲到的内容。

老师没有明确说明：

- 每天练习时长；
- 每项练习的次数；
- 是否需要录音；
- 是否需要发给老师；
- 截止时间。

因此，不自行设定以上要求。

## 复习时只检查本节已讲的点

- [ ] 唇颤音时先放松，持续送气；注意吸气与气息是否撑住。
- [ ] 长音最后一个音不松掉，位置立住。
- [ ] 声音往前、找鼻子，不找后脑勺。
- [ ] 口腔保持竖向打开；高音时更开，不横扁。
- [ ] 咬字用舌头完成，不用下巴乱动；不因咬字失去正确状态。
- [ ] 唱《依然爱你》时不偷偷加劲、不用嗓子；“但”“到”等开头字轻轻过去。
- [ ] 复习本节练到的歌词，重点回忆老师对“亮”“一年一年又一年”“唯一永远不改变”“但”“我”“幸福”的要求。
