# 声乐第 2 课｜课中问题

## 课程主题与进度

**主题：** 基础发声练习 + 《依然爱你》。

**本节目标：** 继续建立基础发声状态，重点练习放松、气息、口腔打开和共鸣位置，并将这些基础状态用于《依然爱你》。

**课堂内容：**

- 基础练习：放松、唇颤音、气息、鼻腔位置、共鸣位置、口腔打开、五声音阶、高音口型。
- 歌曲练习：从上节课的位置继续，练至“到最后一定会依然爱你”。具体歌词以课堂版本和老师示范为准。

## 1. 基础练习：老师明确要求

| 练习/方向 | 老师要求 | 我的主要问题 |
| --- | --- | --- |
| 放松 + 唇颤音 | 嘴巴闭上，用气让嘴唇持续震动；不要执着于动作是否“标准”，想着闭嘴、吐气即可。 | 气息没撑住；没有吸气。 |
| 长音保持 | 最后一个音要“立住”，不能掉下来或懈怠；最高位置要保持。 | 最后一个音容易松掉。 |
| 鼻腔位置 | 找鼻子的感觉，往前唱；不要找“后脑勺最顶深的位置”。 | 容易把声音放得靠后。 |
| 竖向口腔 | 不能扁，要竖起来；练“呜”时也要把嘴巴竖起来。 | 嘴巴和声音偏扁。 |
| 吹蜡烛气息 | 在“吹蜡烛”的持续送气基础上唱音。 | 气息不够、声音通道不够。 |
| 共鸣 | 鼻子、口腔、胸腔要均衡；男声可略多胸腔，但不要突出单一位置。 | 容易只寻找某一个“最震”的位置。 |
| 五声音阶 | 五个音尽可能平均，像一条线或滚动的球。 | 需继续保持每个音均匀。 |
| 张嘴 / 高音口型 | 下巴尽量不动，咬字用舌头完成；嘴巴保持打开，高音越高越开。 | 老师认为本节最大的毛病是唱歌时基本不张嘴，导致声音憋。 |

## 2. 发声时反复纠正的重点

### 气息、放松与通道

- 气息没撑住、没有吸气、气息基本没有时，要多给一点“肚子的气息”。
- 嘴巴、身体、脸和嘴唇都要放松；“嘴唇不要有存在感”。
- 持续送气，给声音通道；如果口腔打不开，气息没有地方走。

### 声音位置与音色

- 声音要往前，找鼻子，不要找后脑勺。
- 低音时即使自己感觉不到鼻子，老师仍说实际上能听到该位置。
- 老师指出声音太扁、太靠后；处理方向是往前、找鼻子、张嘴。

### 咬字与用力

- 不要为了字先失去正确状态；但唱歌时舌头必须工作，字要正常咬。
- 不要用嗓子、偷偷加劲或把开头字“打出去”。
- “但”“到”等字要轻轻过去。

## 3. 《依然爱你》：已练到的处理

| 歌词/片段 | 老师的处理要求或反馈 |
| --- | --- |
| `一闪一闪亮晶晶` | “亮”字张嘴；不要脖子往前顶，只张嘴。 |
| `留下岁月的痕迹` | 声音太扁；继续张嘴。 |
| `我的世界的中心依然还是你` | 腔体打开、嘴唇放松，不要往里包。 |
| `一年一年又一年` | 舌头没有工作，要正常咬字。 |
| `飞逝竟在一转眼` | “飞逝”可以咬清楚一点。 |
| `唯一永远不改变` | 仍黏糊的原因不是没张嘴，而是张嘴太慢；要一下到位，练快张嘴速度。 |
| `我不像从前的自己` | 老师评价“非常好”。 |
| `但在我眼中你的笑` | “但”太重，要放松、轻一点；后一次被评价“刚才这句非常好，记住这个感觉”。 |
| `日子只能往前走` | 声音太扁；往前唱、找鼻子、张嘴；不要像咬牙切齿。 |
| `我依然爱你` | “我”太低；用气声多带一点。 |
| `我依然珍惜` | 觉得高一点就开始用劲；老师说本歌当前尚未出现对你很难的高音，不必加劲或偷偷用嗓子。 |
| `幸福` | “福”字嘴巴小正常；若要更好听可再竖一点，因“福”和“乌”发音接近。 |

## 4. 本节被肯定的状态

- 老师多次给出“这个好”“对了”“很好”“非常好”“好多了”等肯定。
- “我不像从前的自己”被评价“非常好”。
- “但在我眼中你的笑”后一次被评价“刚才这句非常好，记住这个感觉”。
- 老师还表示部分正确状态“已经完全可以了”。
