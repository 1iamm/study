# 声乐课

当前学习重点：基础发声练习，以及歌曲《依然爱你》。

## 目录约定

每节课使用一个独立目录，且只保留两份核心笔记：

```text
lessons/lesson-XX/
├── class-questions.md  # 课中练习、老师纠正、唱歌问题、待补充项
└── homework.md         # 老师明确布置的练习与作业
```

每次 ChatGPT Record 结束后，在当前对话向 Codex 索取声乐课提取提示词；将提示词发送给生成了 Record 的 ChatGPT 聊天，再把输出完整贴回给 Codex。Codex 会把内容归档到对应课次的两个文件中。

## 记录原则

- 只以老师明确说过、转写中可靠保留的内容为准。
- 练习的名称、音高、调性、速度、次数、时长和歌曲小节等细节听不清时，一律标为“待补充”；若影响整理或作业执行，直接向学习者提问。
- 不根据转写自行判断嗓音疾病、声带状态或给出医疗建议。
